# Söhne Font Files

Place your Söhne web font files (`.woff2` format) in this directory.

## Required files:
- `soehne-light.woff2` (weight 300)
- `soehne-regular.woff2` (weight 400)
- `soehne-medium.woff2` (weight 500)

## Where to get Söhne:
Purchase from Klim Type Foundry: https://klim.co.nz/retail-fonts/soehne/

## File naming:
Make sure the files are named exactly as listed above, or update the `@font-face` declarations in `src/app/globals.css` to match your file names.
